## 🚀 Proyecto Integrador: TalleresJetpack
Este es el proyecto central que agrupa los 5 talleres prácticos del semestre en una sola aplicación con navegación fluida.

| Taller | Nombre | Tecnologías Clave | Descripción |
| :--- | :--- | :--- | :--- |
| **01** | **Hola Compose** | `Text`, `Column`, `Row`, `Modifier` | Mi primera interfaz declarativa (Tarjeta de Perfil). |
| **02** | **Lista de Tareas** | `remember`, `MutableState`, `LazyColumn` | Gestión de estado reactivo y navegación entre pantallas. |
| **03** | **App del Clima** | `Retrofit`, `MVVM`, `StateFlow` | Consumo de la API de OpenWeatherMap en tiempo real. |
| **04** | **Finanzas Room** | `Room`, `Hilt`, `Clean Architecture` | Persistencia local de ingresos y gastos con inyección de dependencias. |
| **05** | **Asistente IA** | `CameraX`, `ML Kit`, `Generative AI` | Reconocimiento de ingredientes por cámara para generar recetas. |

## 📂 Otros Proyectos del Semestre
Además del proyecto integrador, este repositorio contiene aplicaciones independientes que exploran diversas funcionalidades de Android.

* **📰 NewApp:** Aplicación avanzada de noticias con una experiencia de usuario (UX) pulida y patrones de diseño modernos.
* **🦸 SuperHeroApp:** Interfaz de tarjetas con Material Design y manejo de listas detalladas de personajes.
* **⛩️ AnimeApp:** Exploración del consumo de datos externos y visualización de recursos multimedia.
* **⚖️ IMCApp:** Calculadora de salud básica para practicar lógica de negocio y captura de datos.
* **✅ TodoApp:** Gestor de tareas independiente enfocado en la persistencia y estados de usuario.
* **🧪 JetpackCompose:** Laboratorio de pruebas para componentes básicos y experimentación inicial con el toolkit.

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Kotlin
* **UI Framework:** Jetpack Compose (Material 3)
* **Arquitectura:** MVVM + Clean Architecture
* **Base de Datos:** Room
* **Red:** Retrofit + GSON
* **Inyección de Dependencias:** Dagger Hilt
* **IA Generativa:** Gemini Code Assist, ChatGPT, Claude.ai
